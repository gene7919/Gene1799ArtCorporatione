# Gene1799 AI Agent

Sistema intelligente basato su Microsoft Agent Framework

## Setup

```bash
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
pip install -r requirements.txt
```

## Esecuzione

```bash
python main.py
```

## Struttura

- `main.py` - Entry point principale
- `agent.py` - Logica dell'agent
- `requirements.txt` - Dipendenze Python
