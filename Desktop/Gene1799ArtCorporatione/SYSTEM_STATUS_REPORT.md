```bash
TELEGRAM_BOT_TOKEN=<your-token>
TELEGRAM_CHANNEL_ID=<your-channel>
TELEGRAM_ADMIN_ID=<your-admin-id>
RENDER_API_KEY=<your-api-key>
AZURE_CLIENT_ID=<your-client-id>
AZURE_CLIENT_SECRET=<your-secret>
AZURE_TENANT_ID=<your-tenant-id>
AZURE_SUBSCRIPTION_ID=<your-subscription>
ENCRYPTION_KEY=<your-256-byte-key>
```

### Step 2: Local Setup
```bash
# Configure local environment
npm install
cp backend/.env.example backend/.env
# Edit .env with your credentials

# Test locally
npm test
npm run lint
```

### Step 3: Deploy to Render
```bash
# Push to trigger GitHub Actions
git add .
git commit -m "Configure secrets for deployment"
git push origin main
# Watch Actions > Deploy workflow
```

### Step 4: Deploy to Azure
```bash
# Use Azure Integration
node -e "const A = require('./backend/src/azure-integration'); \
  const a = new A(); \
  a.authenticate().then(() => \
    a.createResourceGroup()).then(() => \
    a.deployTemplate('complete'))"
```
