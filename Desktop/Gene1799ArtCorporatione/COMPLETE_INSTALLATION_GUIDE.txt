🔧 TROUBLESHOOTING
════════════════════════════════════════════════════════════════════════════════

Service Won't Start?
  1. Check Docker is running
  2. Run: docker ps (should show containers)
  3. Check ports aren't in use:
     netstat -ano | findstr :3000
  4. If port in use, kill process:
     taskkill /PID XXXX /F

Port Already in Use?
  • Run service-coordinator.ps1 -Command Status
  • It will show which service is using which port
  • Can start on different port in .env file

Ollama Not Found?
  • Check if Ollama is installed: https://ollama.ai/
  • Start Ollama: ollama serve
  • Check models: ollama list

GPU Not Detected?
  • Make sure NVIDIA drivers installed
  • Run: nvidia-smi (verify GPU works)
  • Check CUDA: nvidia-smi -L

MongoDB Connection Error?
  • Verify Docker is running
  • Run: docker ps (check MongoDB container)
  • Reset Docker: docker-compose down && docker-compose up -d
